直線 ℓ のまわりの回転体の体積

領域 D（0 ≦ z ≦ cos y，0 ≦ y ≦ π/2）を，点 (1, 0, 0) を通り y 軸に平行な直線 ℓ のまわりに回転した立体 T

軸に垂直な平面で切る

平面 y = t 上で，D の切り口は x = 0, 0 ≦ z ≦ cos t の線分 PQ。

最も近い点・最も遠い点

r = 1、R = √(1 + cos²t) = 1.225

断面積

S(t) = π(R²−r²) = π cos²t = 1.571

体積

V = ∫0π/2 π cos²t dt = π²⁄4
