立方数の和は、和の2乗になる

1辺 k の立方体を厚さ1の板に切り分けて床に敷き詰めると、1辺が 1+2+…+n の正方形の板がぴったりできあがります。体積が変わらないので、1³+2³+…+n³ = (1+2+…+n)²。

経過
立方体の数 n
速さ
  1. 立方体を並べる1辺 1, 2, …, n の立方体。体積はそれぞれ 1³, 2³, …, n³。どれも1辺 k、厚さ1の正方形の板を k 枚重ねたものと見られる。
  2. 床に正方形の枠を用意する1辺が 1+2+…+n の正方形。奥の角から、幅 1, 2, 3, … の区切りをつけておく。
  3. 板をL字に敷き詰める立方体 k の k 枚の板は、幅 k のL字の部分にぴったり収まる。k が偶数のときは1枚だけ半分に切って両端に置く。
  4. 体積を比べるできあがったのは1辺 1+2+…+n、厚さ1の板。体積は (1+2+…+n)²。切って並べ替えただけなので、立方体の体積の合計と等しい。

体積の計算

なぜL字に収まるのか：Tk = 1+2+…+k とすると、L字の面積は
Tk² − Tk−1² = (Tk − Tk−1)(Tk + Tk−1) = k · k² = k³
で、ちょうど立方体 k の体積と同じになります（Tk + Tk−1 = k²）。
